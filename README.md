# debate-fallacy-detector

Logical Fallacy Detection in Presidential Debates

This repository contains a Jupyter Notebook that explores detecting logical fallacies in debate transcripts using a Random Forest classifier and LLM-based classification (Dartmouth-hosted models via LangChain wrappers).

## Contents
- `CS72_Final_Project.ipynb` — the main notebook with data loading, preprocessing, a Random Forest baseline, LLM helpers, and visualization cells.
- `parse_transcripts.py` — Python script to parse debate transcripts from `Debate Transcripts/` into normalized CSV format.
- `Debate Transcripts/` — raw debate transcript text files (1960-2020) organized by year.
- `all_debates_combined.csv` — parsed and normalized debate data (generated by `parse_transcripts.py`).
- `parsed_debates/` — individual CSV files for each debate (generated by `parse_transcripts.py`).
- Optional: `.env` (local, not committed) — contains API keys for Dartmouth LLM access.

## Quick start
1. Clone the repo and open the notebook in VS Code or JupyterLab.

2. Create a local `.env` file with Dartmouth LLM API Keys 
    - Dartmouth Students can do this for free by following the instructions [here](https://pypi.org/project/langchain-dartmouth/)
    - Be sure to secure the file and ignore it in git

3. Open `CS72_Final_Project.ipynb`, restart the kernel, and run the top cells in order:
	- Run the install cell (only when needed) to ensure packages are installed in the kernel.
	- Run the `.env` loader cell to load API keys into `os.environ`.
	- Run the imports/version-check cell.

## Parsing debate transcripts
If you need to re-parse the debate transcripts or add new ones:

```bash
python3 parse_transcripts.py
```

This will:
- Parse all `.txt` files in `Debate Transcripts/` (handles varying formats from 1960-2020)
- Extract speaker names, normalize them, and split into individual statements
- Output `all_debates_combined.csv` (ready for notebook use)
- Create individual CSV files in `parsed_debates/` folder

The parser handles:
- Multiple debate formats across decades
- Speaker name variations (MR. NIXON, OBAMA, etc.)
- Moderator identification
- Date extraction from filenames

Running the analysis
- The notebook loads the Logical Fallacy dataset (Hugging Face dataset path is referenced in the notebook).
- Load parsed debate data with: `pd.read_csv('all_debates_combined.csv')`
- It preprocesses and filters fallacy types, up-samples minority classes, trains a TF-IDF + RandomForest baseline, evaluates, and then runs LLM-based classification using `ChatDartmouth` wrappers.
